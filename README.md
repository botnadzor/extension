# Botnadzor extension

Botnadzor browser extension highlights bots on [vk.com](https://vk.com) and VK-related sites.

Learn more at [botnadzor.org/extension](https://botnadzor.org/extension) (ru).

---

Браузерное расширение Ботнадзор подсвечивает ботов на [vk.com](https://vk.com) и связанных сайтах.

Подробнее: [botnadzor.org/extension](https://botnadzor.org/extension).
